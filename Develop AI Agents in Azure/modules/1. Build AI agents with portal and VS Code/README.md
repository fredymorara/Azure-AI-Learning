# Module 01: Build AI Agents with Portal and VS Code

## Objective
Learned to architect an AI agent using the Microsoft Foundry portal, configure grounding data (IT policy) and tools (File Search, Code Interpreter), and interact with the agent programmatically via the Foundry Toolkit for VS Code.

## Key Skills
- Azure AI Foundry Project management
- Retrieval-Augmented Generation (RAG) configuration
- VS Code integration with Azure AI Foundry
- Python-based agent interaction
